Rights and attribution
======================

No additional license is applied to the original research code in this
repository. Public access alone does not grant a permissive software license.
Existing copyright and upstream notices remain applicable. Contact the
repository owner for permissions beyond those provided by applicable law.

Third-party datasets and software retain their own terms. See
DATA_LICENSES.rst for the bundled UCI data and the download-only sources.
Dependencies are installed from their distributions, not vendored here;
requirements-lock.txt pins the versions used. In particular, fmvmm 3.0.2
provides the package Dirichlet and Student-t comparators. The independently
implemented logistic-Dirichlet, Gaussian-control and bounded skew-normal
kernels are in scripts/.
